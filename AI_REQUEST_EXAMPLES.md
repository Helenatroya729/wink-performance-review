## Важные детали:

### 1. Общие поля для обоих запросов:
- `employee_name` - имя сотрудника
- `position` - должность
- `self_score`, `manager_score`, `peer_score`, `potential_score`, `total_score` - численные оценки
- `self_assessment` - массив с детальной самооценкой (вопросы, баллы, комментарии)
- `manager_evaluation` - объект с оценкой руководителя
- `peer_reviews` - массив с оценками коллег
- `potential_assessment` - оценка потенциала (9-Box матрица)
- **`company_triggers`** - массив триггерных слов и рекомендаций компании (новое!)

### 2. Триггеры компании (company_triggers):
Это ключевые слова, которые HR устанавливает для всей компании. Если в комментариях или оценках встречаются эти слова, AI должен учитывать соответствующие корпоративные рекомендации.

**Пример триггеров:**
- "лидерство" → рекомендация о курсах по лидерству
- "коммуникация" → рекомендация о тренингах по коммуникации
- "инициатива" → рекомендация о кросс-функциональных проектах
- "делегирование" → рекомендация о курсах по делегированию

### 3. Различия между двумя типами рекомендаций:

#### Для сотрудника (`/api/results-and-plan`):
- Фокус: персональное развитие
- Тон: мотивирующий, поддерживающий
- Структура: достижения → области улучшения → план развития
- Формат: bullet points, четкие шаги

#### Для руководителя (`/api/steps-of-manager`):
- Фокус: управленческие действия
- Тон: практичный, конкретный
- Структура: приоритетные шаги → мониторинг → риски
- Формат: нумерованный список с деталями

### 4. Как добавить триггеры в запрос:

Нужно модифицировать клиентский код, чтобы передавать триггеры из HRDashboard в CalculationResults. Триггеры можно получить через:
- Context API
- Props drilling
- State management (Redux/Zustand)
- API endpoint `/api/hr/triggers` (рекомендуется)

## Тестирование через curl:

```bash
# Тест генерации рекомендаций для сотрудника
curl -X POST http://localhost:8000/api/results-and-plan \
  -H "Content-Type: application/json" \
  -d @employee_recommendation_request.json

# Тест генерации управленческих рекомендаций
curl -X POST http://localhost:8000/api/steps-of-manager \
  -H "Content-Type: application/json" \
  -d @manager_recommendation_request.json
```

Где `employee_recommendation_request.json` и `manager_recommendation_request.json` - файлы с примерами выше.
