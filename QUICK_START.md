## ВАЖНО: Первый запуск после установки Node.js

После установки Node.js **обязательно ПЕРЕЗАГРУЗИТЕ КОМПЬЮТЕР** или перезапустите PowerShell, чтобы Node.js добавился в PATH.

---

## Способ 1: САМЫЙ ПРОСТОЙ - Через батник (рекомендуется)

1. **Просто дважды кликните на файл `START.bat`** в папке проекта
2. Откроются 2 окна: сервер и клиент
3. Через несколько секунд браузер откроется автоматически
4. Готово!

---

## Способ 2: Через PowerShell

### Шаг 1: Откройте PowerShell в папке проекта

Правой кнопкой мыши в папке `Расти в IT` → "Открыть в терминале"

### Шаг 2: Добавьте Node.js в PATH (только для текущей сессии)

```powershell
$env:Path += ";C:\Program Files\nodejs"
```

### Шаг 3: Проверьте, что Node.js работает

```powershell
node --version
npm --version
```

Должны увидеть версии (например, v25.0.0 и 11.6.2)

### Шаг 4: Запустите серверы

**Вариант А) Запуск через скрипт:**
```powershell
.\START.ps1
```

**Вариант Б) Запуск вручную (2 окна PowerShell):**

**Окно 1 - Backend:**
```powershell
cd server
npm run dev
```

**Окно 2 - Frontend:**
```powershell
cd client
npm start
```

## 🛠️ Если Node.js не найден

### Решение 1: Перезагрузите компьютер
После установки Node.js - **перезагрузите компьютер**. Это самый надежный способ.

### Решение 2: Добавьте Node.js в PATH вручную (постоянно)

1. Нажмите `Win + X` → "Система"
2. "Дополнительные параметры системы"
3. "Переменные среды"
4. В разделе "Системные переменные" найдите `Path`
5. Нажмите "Изменить"
6. Добавьте: `C:\Program Files\nodejs`
7. Нажмите "ОК" везде
8. **Перезапустите PowerShell**

### Решение 3: Используйте START.bat
Батник автоматически добавляет Node.js в PATH при запуске.

## 🐛 Частые проблемы

### Проблема: "npm не распознано"
**Решение**: 
1. Перезагрузите компьютер
2. Или добавьте в PATH: `$env:Path += ";C:\Program Files\nodejs"`

### Проблема: Порт 3000 уже занят
**Решение**: 
1. Закройте другие React приложения
2. Или измените порт в `client/.env`: `PORT=3001`

### Проблема: Порт 5000 уже занят
**Решение**: 
1. Закройте другие серверы
2. Или измените порт в `server/.env`: `PORT=5001`

### Проблема: Браузер не открывается автоматически
**Решение**: 
Откройте вручную: http://localhost:3000
