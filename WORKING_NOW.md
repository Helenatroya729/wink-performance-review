## 🔧 Технические детали

### Backend (server-new.js)
```javascript
POST /api/goals
- Принимает: cycle_id, title, description, expected_results, key_tasks, expected_deadline
- Автоматически определяет goal_number
- Использует user_id из JWT токена
- Возвращает созданную цель
```

### Frontend (EmployeeDashboard.js)
```javascript
- useState для showGoalForm (управление модальным окном)
- useState для newGoal (данные формы)
- handleCreateGoal() - отправка на API
- loadData() - перезагрузка после создания
- onClick для всех quick action карточек
```

### Модальное окно
- Затемненный overlay
- Центрированное окно
- Закрывается при клике вне окна
- Форма валидируется (required поля)
- Красивые стили в Dashboard.css

```javascript

DELETE /api/goals/:id          // Удалить цель
POST   /api/assessments/self   // Самооценка
POST   /api/reviews/peer       // Оценка коллеги
GET    /api/results/me         // Мои результаты
```
