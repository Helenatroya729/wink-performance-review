# Функционал 3: Калькуляция результатов Performance Review

## Описание

Страница калькуляции предназначена **только для HR и администраторов**. Она позволяет:
- Суммировать и отображать общие баллы из Функционала 2 (самооценка, оценка руководителя, оценки коллег)
- Вносить инструкции по подсчету баллов
- Добавлять текст подведения итогов для каждого сотрудника

## Доступ

- **HR / Admin**: Полный доступ ко всем сотрудникам
- **Сотрудники / Менеджеры**: НЕ имеют доступа к калькуляции

## Как использовать

### Для HR:

1. **Перейти к калькуляции:**
   - Откройте HR Dashboard
   - Перейдите на вкладку "Калькуляция баллов"
   - Нажмите кнопку "Калькуляция" рядом с именем сотрудника

2. **Просмотр результатов:**
   - Выберите сотрудника из выпадающего списка
   - Система автоматически рассчитает итоговый балл
   - Отобразятся все компоненты оценки:
     * Самооценка (1-10 баллов)
     * Оценка руководителя (1-10 баллов, если применимо)
     * Оценки коллег (1-10 баллов)

3. **Формула расчета:**
   ```
   Итоговый балл = (Самооценка + Оценка руководителя + Оценки коллег) / Количество заполненных оценок
   ```

4. **Для руководителей:**
   - Оценка руководителя НЕ учитывается
   - Формула: (Самооценка + Оценки коллег) / 2

5. **Подведение итогов:**
   - Блок "Подсчет баллов" - инструкция по расчету (можно редактировать для компании)
   - Блок "Подведение итогов" - текстовое поле для выводов HR по каждому сотруднику
   - Нажмите "Сохранить итоги" для сохранения

## Структура страницы

### 1. Выбор сотрудника
- Выпадающий список всех сотрудников
- Показывает: ФИО, должность, текущий балл

### 2. Итоговый балл
- Крупный блок с финальной оценкой
- Статус оценки (Завершено / В процессе)

### 3. Суммирование баллов
Три карточки с оценками:
- **Самооценка**: средний балл, количество ответов
- **Оценка руководителя**: балл (если есть)
- **Оценки коллег**: средний балл, количество отзывов

### 4. Формула расчета
Визуализация расчета итогового балла с реальными числами

### 5. Блок инструкций
Текст с объяснением методики подсчета баллов

### 6. Подведение итогов
Текстовое поле для HR для записи:
- Выводов по сотруднику
- Планов развития
- Ключевых достижений
- Областей для улучшения

### 7. Детальная информация
- Период оценки
- Количество заполненных оценок
- Дата последнего обновления

## API Endpoints

### Получить результаты калькуляции
```
GET /api/employee/calculation-results/:id
```

**Параметры:**
- `id` - ID сотрудника

**Ответ:**
```json
{
  "employeeId": 3,
  "employeeName": "Иван Иванов",
  "role": "employee",
  "totalScore": 7.50,
  "selfScore": 8.00,
  "managerScore": 7.00,
  "peerScore": 7.50,
  "selfAssessmentCount": 5,
  "peerReviewsCount": 3,
  "evaluationsCount": 3,
  "maxExpectedEvaluations": 3,
  "status": "completed",
  "cycleName": "Первое полугодие 2025",
  "lastUpdated": "2025-10-24T10:00:00.000Z",
  "instructions": null
}
```

### Сохранить итоги
```
POST /api/employee/save-summary/:id
```

**Body:**
```json
{
  "summaryText": "Сотрудник показал отличные результаты..."
}
```

## Маршруты

- **URL**: `/calculation-results/:employeeId?`
- **Доступ**: Только HR и Admin
- **Компонент**: `CalculationResults.js`

## Интеграция с другими разделами

1. **HR Dashboard → Калькуляция:**
   - Таблица баллов сотрудников
   - Кнопка "Калькуляция" для каждого сотрудника

2. **База данных:**
   - Создается таблица `employee_summaries` для хранения итогов
   - Привязка к циклу оценки
   - Timestamps для отслеживания изменений

## Статусы оценки

- **Завершено** (зеленый): Все оценки заполнены
- **В процессе** (оранжевый): Частично заполнено

## Примечания

- Руководители НЕ получают оценку от руководителя (это они сами)
- Сотрудники НЕ имеют доступа к калькуляции
- Калькуляция доступна только HR для подведения итогов
- Итоговый балл рассчитывается автоматически
- Формула расчета отображается с реальными значениями
