# Анализ Excel файла и создание структуры БД

## Шаг 1: Положите Excel файл в папку проекта

Скопируйте файл `Кейс_Механика оценки_2025.xlsx` в папку:
```

```

## Шаг 2: Установите Python библиотеки

```powershell
pip install pandas openpyxl numpy psycopg2-binary sqlalchemy
```

Или установите все сразу:
```powershell
pip install -r requirements.txt
```

## Шаг 3: Запустите анализ

```powershell
python analyze_excel.py "Кейс_Механика оценки_2025.xlsx"
```

Или если файл один в папке, просто:
```powershell
python analyze_excel.py
```

## Что делает скрипт:

✅ Читает все листы Excel файла
✅ Анализирует структуру каждого листа:
   - Количество строк и столбцов
   - Типы данных в каждом столбце
   - Количество пустых значений
   - Уникальные значения
   - Примеры данных

✅ Определяет потенциальные ключи:
   - PRIMARY KEY (уникальные столбцы без пустых значений)
   - FOREIGN KEY (столбцы с _id или id в названии)

✅ Генерирует SQL схему для PostgreSQL:
   - CREATE TABLE для каждого листа
   - Подходящие типы данных (INTEGER, VARCHAR, TEXT, TIMESTAMP и т.д.)
   - PRIMARY KEY и индексы

✅ Сохраняет результат в JSON файл для дальнейшего использования

## Результат

После выполнения вы получите:
1. Подробный анализ в консоли
2. SQL схему для создания таблиц PostgreSQL
3. JSON файл с полным анализом (для использования в коде)
