Pipeline данных

Этап 0: Инициализация

HR создает цикл оценки → Распределяет задачи → Сотрудники получают 3 задачи → Выбирают респондентов для 360

↓

Функционал 1: Постановка целей

Сотрудник создает цель → Добавляет 3 подзадачи с дедлайнами → Руководитель согласовывает

↓

Функционал 2: Оценки

2.1: Сотрудник проходит самооценку (self_assessments)
2.2: Коллеги оценивают сотрудника (peer_reviews)
2.3: Руководитель оценивает сотрудника (manager_reviews)
2.4: Руководитель оценивает потенциал → 9-box матрица (potential_assessments)

↓

Функционал 3: Расчет итогов

Собираются все оценки → Рассчитывается total_score и rating (0-10) → Определяется rating_category (outstanding/good_result/low_result/no_result) → Сохраняется в final_reviews

↓

Функционал 4: Рекомендации

Система проверяет recommendation_triggers → Генерирует employee_recommendations (обучение, повышение, ротация) → Создается development_plan (IDP)
