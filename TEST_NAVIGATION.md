# 🧪 ТЕСТ: Навигация из уведомлений

## ✅ Что исправлено:

### Проблема:
При клике на уведомление "Анна Сидорова запрашивает вашу оценку" страница PeerFeedback открывалась, но показывалась вкладка "Запросить оценку" вместо "Ожидают оценки".

### Решение:

1. **Добавлен импорт `useLocation`** в PeerFeedback.js:
   ```javascript
   import { useNavigate, useLocation } from 'react-router-dom';
   ```

2. **Добавлен useEffect для чтения параметра `tab` из URL**:
   ```javascript
   const location = useLocation();
   
   useEffect(() => {
     const searchParams = new URLSearchParams(location.search);
     const tab = searchParams.get('tab');
     if (tab && ['request', 'pending', 'received'].includes(tab)) {
       setActiveTab(tab);
     }
   }, [location.search]);
   ```

3. **Уведомление уже использует правильный URL**:
   ```javascript
   action: () => navigate('/peer-feedback?tab=pending')
   ```
