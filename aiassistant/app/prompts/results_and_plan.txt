Имя: {employee_name}
Должность: {position}
Статус оценки: {evaluation_status}

ЧИСЛОВЫЕ ПОКАЗАТЕЛИ:
Самооценка: {self_score}/10

Итоговый балл: {total_score}/10

ДЕТАЛЬНАЯ САМООЦЕНКА СОТРУДНИКА:
{self_assessment}

ОЦЕНКА РУКОВОДИТЕЛЯ:
{manager_evaluation}

ОТЗЫВЫ КОЛЛЕГ (360°):
{peer_reviews}

ОЦЕНКА ПОТЕНЦИАЛА (9-BOX):
{potential_assessment}

ЗАДАЧА:
Опиши конкретные ДОСТИЖЕНИЯ сотрудника за оцениваемый период:
- Выдели ключевые успехи, упомянутые в самооценке, оценке руководителя и отзывах коллег
- Укажи конкретные проекты и результаты
- Отметь сильные стороны, которые отмечают коллеги
- Используй конкретные цитаты и примеры из комментариев
- Будь конкретным и фактическим
- Объем: 150-250 слов

ТРЕБОВАНИЯ:
1. Фокусируйся ТОЛЬКО на достижениях и успехах
2. Используй данные из всех источников оценки
3. Приводи конкретные примеры и цифры
4. Пиши в позитивном тоне
5. НЕ упоминай области для улучшения в этой секции
6. НЕ используй эмодзи и маркдаун форматирование и жирный шрифт.

Начни прямо с описания достижений, без вступлений.

=== DEVELOPMENT_PLAN ===

Ты - опытный HR-менеджер. На основе результатов комплексной оценки сотрудника (360°) составь конкретный ПЛАН РАЗВИТИЯ.

ИНФОРМАЦИЯ О СОТРУДНИКЕ:
Имя: {employee_name}
Должность: {position}
Статус оценки: {evaluation_status}

ЧИСЛОВЫЕ ПОКАЗАТЕЛИ:
Самооценка: {self_score}/10
Оценка руководителя: {manager_score}/10
Оценка коллег (360°): {peer_score}/10
Итоговый балл: {total_score}/10

ДЕТАЛЬНАЯ САМООЦЕНКА СОТРУДНИКА:
{self_assessment}

ОЦЕНКА РУКОВОДИТЕЛЯ:
{manager_evaluation}

ОТЗЫВЫ КОЛЛЕГ (360°):
{peer_reviews}

ОЦЕНКА ПОТЕНЦИАЛА (9-BOX):
{potential_assessment}

ЗАДАЧА:
Составь конкретный actionable ПЛАН РАЗВИТИЯ сотрудника:

1. РАЗВИТИЕ СИЛЬНЫХ СТОРОН (50-80 слов)
   - Конкретные шаги для усиления выявленных сильных сторон
   - Как использовать их для большей эффективности

2. РАБОТА НАД ОБЛАСТЯМИ УЛУЧШЕНИЯ (80-120 слов)
   - Конкретные действия для улучшения слабых мест
   - Рекомендации по обучению: курсы, тренинги, менторство, книги
   - Практические задачи для развития навыков

3. КАРЬЕРНОЕ РАЗВИТИЕ (60-100 слов)
   - Предложения по новым проектам или ролям
   - Возможности для повышения (учитывая оценку потенциала)
   - Развитие лидерских качеств (если применимо)

4. КОНКРЕТНЫЕ ШАГИ С СРОКАМИ (60-100 слов)
   - Ближайшие 3 месяца: что делать
   - 3-6 месяцев: промежуточные цели
   - 6-12 месяцев: долгосрочные цели

ТРЕБОВАНИЯ:
1. Будь максимально конкретным - указывай конкретные курсы, тренинги, книги
2. Устанавливай реалистичные сроки
3. Учитывай позицию в 9-Box матрице для приоритизации действий
4. План должен быть actionable - чтобы сотрудник мог начать действовать сразу
5. Балансируй между развитием навыков и карьерным ростом
6. НЕ используй эмодзи и маркдаун форматирование и жирный шрифт
7. Общий объем: 250-400 слов

Структурируй план по указанным пунктам. Начни прямо с плана, без вступлений.
