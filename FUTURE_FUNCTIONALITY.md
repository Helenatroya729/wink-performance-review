# Будущий функционал системы WINK Performance Review

## Обзор

На основе детального анализа Excel файла "Кейс_Механика оценки_2025.xlsx" определены все требования к функционалу системы. База данных полностью соответствует структуре данных из Excel.

## Проверка соответствия Excel скринам: ПОЛНОЕ

### Лист 1: Распределение задач
- Задачи с номерами
- Руководители направлений (несколько на задачу)
- Участники с указанием отдела/роли
- Дополнительные пометки
Статус: РЕАЛИЗОВАНО в tables: tasks, task_leads, task_participants, task_annotations

### Лист 2: Этап 0 - Вводный опрос
- Выбор до 3 задач сотрудником
- Выбор респондентов по каждой задаче
Статус: РЕАЛИЗОВАНО в tables: employee_tasks, selected_respondents

### Лист 3: Функционал 1 - Цели и задачи
- До 5 целей
- Для каждой цели: название, сроки, ожидаемые результаты, ключевые задачи
- До 3 задач под каждой целью
Статус: РЕАЛИЗОВАНО в tables: employee_goals (расширен), goal_tasks (добавлен)

### Лист 4: Функционал 2 - Самооценка сотрудника
- Выбор задачи из выпадающего списка
- Вопросы с разными типами ответов (текст, шкала 0-10)
- Калькуляция баллов: 0-7 = 1, 8-12 = 2, 13-20 = 3
Статус: РЕАЛИЗОВАНО в tables: self_assessment_questions, self_assessments

### Лист 5: Функционал 2 - Оценка 360 от респондентов
- Выбор респондентов из списка
- Автоматический показ задачи
- Вопросы со шкалой и текстом
- Калькуляция баллов: 0-7 = 1, 8-12 = 2, 13-20 = 3
Статус: РЕАЛИЗОВАНО в tables: peer_review_questions, peer_reviews

### Лист 6: Функционал 2 - Оценка 360 от руководителя
- Просмотр отчета с ответами респондентов
- Формирование общей обратной связи
- Рейтинг: 0-2 нет результата, 3-5 низкий, 6-8 хороший, 9-10 сверхрезультат
- Калькуляция баллов: 0-10 = 1, 11-20 = 2, 21-30 = 3
Статус: РЕАЛИЗОВАНО в tables: manager_review_questions, manager_reviews

### Листы 7-8: Функционал 2 - Оценка потенциала
Профессиональные качества (множественный выбор):
- Ответственность
- Ориентация на результат
- Проактивность
- Открытое мышление
- Командный игрок

Личные качества (чекбоксы да/нет):
- Берет больше ответственности
- Прозрачная коммуникация
- Делится информацией
- Выстраивает работу

Дополнительные вопросы:
- Готовность к росту (1-2 года, 3 года, 3+ лет)
- Является ли преемником
- Справляется с коммуникационными барьерами
- Рефлексирует по результатам
- Желаемая роль
- Уровень интереса к роли (0-10)
- Оценка риска ухода (0-10)

9-box матрица:
- Потенциал: Low/Medium/High
- Результативность: Low/Medium/High

Статус: РЕАЛИЗОВАНО в tables: potential_assessments (расширен), potential_detail_questions, potential_detail_answers

### Лист 9: Функционал 3 - Подведение итогов
- Суммирование баллов из всех оценок
- Вывод итогового результата
- Блок инструкций
Статус: РЕАЛИЗОВАНО в table: final_reviews

### Лист 10: Функционал 4 - Рекомендации
- Триггерные слова в админке
- Автоматическая генерация рекомендаций
- Индивидуальные планы развития
Статус: РЕАЛИЗОВАНО в tables: recommendation_triggers, employee_recommendations, development_plans

## Функционал для реализации

### 1. Модуль управления задачами
- Импорт задач из Excel
- Назначение руководителей и участников
- Добавление аннотаций
- История изменений задач

### 2. Вводный опрос (Этап 0)
- Интерфейс выбора до 3 задач из списка
- Множественный выбор респондентов по каждой задаче
- Валидация: респондент должен быть участником задачи
- Отправка уведомлений респондентам

### 3. Постановка целей (Функционал 1)
- Форма создания до 5 целей
- Поля: название, сроки, ожидаемые результаты, ключевые задачи
- Добавление до 3 задач под каждой целью
- Отправка целей руководителю на утверждение
- Статусы: черновик → отправлено → одобрено/отклонено

### 4. Самооценка (Функционал 2.1)
- Динамическая форма на основе вопросов из БД
- Типы вопросов: текст, шкала 0-10, множественный выбор
- Автоматический подсчет баллов
- Конвертация в категорию: 0-7 = 1, 8-12 = 2, 13-20 = 3
- Сохранение черновиков
- Отправка на проверку

### 5. Оценка 360 от респондентов (Функционал 2.2)
- Список сотрудников, запросивших оценку
- Отображение задачи автоматически
- Форма оценки с вопросами
- Автоматический подсчет баллов
- Конвертация в категорию: 0-7 = 1, 8-12 = 2, 13-20 = 3
- Статус: ожидает → завершено → отклонено

### 6. Оценка 360 от руководителя (Функционал 2.3)
- Просмотр отчета с ответами всех респондентов
- Агрегированная статистика по ответам
- Форма для общей обратной связи
- Рекомендации по формату обратной связи
- Выставление финального рейтинга (0-10)
- Автоматическая категоризация:
  * 0-2: нет результата
  * 3-5: низкий результат
  * 6-8: хороший результат
  * 9-10: сверхрезультат

### 7. Оценка потенциала (Функционал 2.4)
- Множественный выбор профессиональных качеств (5 вариантов)
- Чекбоксы личных качеств (4 варианта)
- Дополнительные вопросы:
  * Готовность к росту (выпадающий список)
  * Является ли преемником (да/нет)
  * Коммуникационные барьеры (да/нет)
  * Рефлексия результатов (да/нет)
  * Желаемая роль (текст)
  * Интерес к роли (шкала 0-10)
  * Риск ухода (шкала 0-10)
- Автоматический расчет баллов потенциала
- Автоматический расчет баллов результативности
- Построение 9-box матрицы: 3x3 сетка
- Визуализация позиции сотрудника в матрице

### 8. Подведение итогов (Функционал 3)
- Автоматическое суммирование всех баллов:
  * Самооценка (0-3)
  * Оценка 360 от респондентов (0-3)
  * Оценка от руководителя (0-3)
  * Оценка потенциала (0-3)
  * Итого: 0-12 баллов
- Вывод итогового рейтинга
- Блок с инструкцией по подсчету баллов
- Статус: черновик → завершено → откалибровано

### 9. Рекомендации (Функционал 4)
- Админка для управления триггерными словами
- Автоматическое сканирование обратной связи
- Поиск триггерных слов (регистронезависимый)
- Генерация рекомендаций на основе найденных триггеров
- Возможность добавления ручных рекомендаций от HR/руководителя
- Создание ИПР (Индивидуальный план развития):
  * Цель развития
  * Действия
  * Срок
  * Статус: запланировано → в работе → завершено → отменено

### 10. Калибровочные сессии
- Создание калибровочной встречи
- Назначение участников
- Просмотр всех сотрудников с оценками
- Групповое обсуждение спорных случаев
- Корректировка рейтингов и позиций в 9-box
- Фиксация причины корректировки
- История изменений

### 11. Дашборд для HR
- Статистика по циклу оценки
- 9-box матрица по всей компании (147 сотрудников)
- Распределение по категориям рейтинга
- Рекомендации по повышению зарплаты:
  * High Potential + High Performance: +15-20%
  * Medium Potential + High Performance или High Potential + Medium Performance: +10-15%
  * Medium Potential + Medium Performance: +5-10%
  * Low Potential + Low Performance: без повышения
- Экспорт данных в Excel
- Фильтры по отделам, руководителям, задачам

### 12. Дашборд для руководителя
- Список подчиненных с их статусами
- 9-box матрица команды (12 сотрудников)
- Прогресс заполнения оценок
- Статистика команды:
  * Количество сотрудников
  * Ожидающих оценки
  * Завершенных оценок
  * Средний рейтинг команды
- Календарь калибровочных сессий

### 13. Дашборд для сотрудника
- Свои цели и прогресс
- Статус самооценки
- Статус оценок 360 (сколько респондентов ответило)
- Полученная обратная связь
- Итоговый рейтинг и позиция в 9-box
- Рекомендации по развитию
- Индивидуальный план развития (ИПР)
- Уведомления

### 14. Уведомления
- Email уведомления:
  * Запрос на оценку 360
  * Напоминание о незаполненных формах
  * Утверждение/отклонение целей
  * Готовность итоговой обратной связи
  * Приглашение на калибровочную сессию
- Push уведомления в интерфейсе
- История уведомлений

### 15. Аудит и безопасность
- Логирование всех действий пользователей
- Сохранение IP адресов
- История изменений оценок
- Права доступа по ролям:
  * employee: только свои данные
  * manager: свои данные + данные подчиненных
  * hr: все данные
  * admin: все данные + настройки системы

### 16. Администрирование
- Управление пользователями
- Управление циклами оценки
- Настройка вопросов для самооценки, 360, оценки потенциала
- Управление триггерными словами
- Настройка формул калькуляции
- Настройка шаблонов форм и блоков интерфейса
- Импорт/экспорт данных
- Интеграция с корпоративными системами (LDAP, 1C, Email)

### 17. Отчеты
- Итоговый отчет по сотруднику (PDF)
- Отчет по команде для руководителя
- Сводный отчет по компании для HR
- 9-box матрица с именами (визуализация)
- Отчет по рекомендациям зарплат
- Отчет по ИПР
- Экспорт в Excel для дальнейшей обработки

### 18. API для интеграции
- REST API для всех операций
- Аутентификация через JWT
- Эндпоинты для:
  * Создание/изменение пользователей
  * Управление циклами
  * Получение оценок
  * Отправка уведомлений
  * Экспорт данных
- Документация Swagger/OpenAPI

## Технический стек

### Backend
- Node.js + Express
- PostgreSQL (схема готова)
- JWT для аутентификации
- Sequelize или TypeORM для работы с БД
- Nodemailer для email уведомлений

### Frontend
- React 18 (уже используется)
- React Router v6 (уже настроен)
- Axios для API запросов
- Recharts для визуализации 9-box матрицы
- React Hook Form для форм
- CSS Modules или Styled Components

### Дополнительно
- Docker для развертывания
- Redis для кэширования сессий
- Winston для логирования
- Jest для тестирования
- GitHub Actions для CI/CD

## Приоритеты разработки

### MVP (Минимальный продукт)
1. Авторизация и управление пользователями
2. Создание цикла оценки
3. Постановка целей (Функционал 1)
4. Самооценка (Функционал 2.1)
5. Базовая оценка 360 от респондентов (Функционал 2.2)
6. Базовая оценка от руководителя (Функционал 2.3)
7. Подведение итогов (Функционал 3)
8. Простой дашборд для каждой роли

### Фаза 2
1. Оценка потенциала и 9-box матрица (Функционал 2.4)
2. Рекомендации и ИПР (Функционал 4)
3. Калибровочные сессии
4. Уведомления
5. Расширенные дашборды

### Фаза 3
1. Импорт задач из Excel
2. Экспорт отчетов
3. API для интеграций
4. Администрирование (настройка вопросов, триггеров)
5. Аудит и логирование

## Оценка трудозатрат

- MVP: 2-3 недели (при команде из 2-3 разработчиков)
- Фаза 2: 2-3 недели
- Фаза 3: 1-2 недели
- Итого: 5-8 недель
