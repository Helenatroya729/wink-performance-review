## 🔧 BACKEND API ENDPOINTS

### Аутентификация ✅
- `POST /api/auth/login` - вход в систему
- `GET /api/auth/me` - получение текущего пользователя

### Пользователи ✅
- `GET /api/users` - список всех пользователей из таблицы users

### Циклы оценки ✅
- `GET /api/cycles` - все циклы из таблицы review_cycles
- `POST /api/cycles` - создание нового цикла

### Цели ✅
- `GET /api/goals` - цели текущего пользователя или всей команды (для менеджера)
- `POST /api/goals` - создание новой цели
- `PUT /api/goals/:id` - обновление цели (в т.ч. утверждение/отклонение)

### Статистика ✅
- `GET /api/dashboard/stats` - реальная статистика из БД:
  ```sql
  SELECT COUNT(*) FROM employee_goals WHERE user_id = ?
  SELECT COUNT(*) FROM users WHERE manager_id = ?
  ```

### Оценка от коллег (360°) ✅
- `GET /api/peer-feedback/colleagues` - список коллег из таблицы users
- `POST /api/peer-feedback/request` - создание запроса в peer_feedback_requests
- `GET /api/peer-feedback/my-requests` - запросы из peer_feedback_requests (requester_id = current)
- `GET /api/peer-feedback/pending-reviews` - запросы из peer_feedback_requests (reviewer_id = current)
- `POST /api/peer-feedback/submit` - сохранение в peer_feedbacks
- `GET /api/peer-feedback/received` - оценки из peer_feedbacks (requester_id = current)
