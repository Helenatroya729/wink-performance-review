# ПРОСТОЕ РЕШЕНИЕ: Используйте локальную сеть

## ВАРИАНТ 1: Презентация на вашем ноутбуке
Просто откройте http://localhost:3000 и показывайте жюри со своего экрана!

## ВАРИАНТ 2: Если жюри в той же WiFi сети
Дайте им адрес: **http://192.168.1.140:3000**

## ВАРИАНТ 3: Быстрый деплой на Netlify Drop

### Шаг 1: Соберите проект
```powershell
cd client
npm run build
```

### Шаг 2: Перетащите папку build на сайт
1. Откройте: https://app.netlify.com/drop
2. Перетащите папку `client/build` на сайт
3. Получите постоянный URL за 10 секунд!

## ВАРИАНТ 4: Telegram Bot (самый креативный!)

Создайте бота и отправьте ссылку через него:
1. Откройте @BotFather в Telegram
2. Создайте бота
3. Отправьте ссылку http://192.168.1.140:3000
4. Жюри переходит по ссылке (если в сети)

## Рекомендация для ХАКАТОНА:

### САМЫЙ БЫСТРЫЙ способ (2 минуты):
1. Соберите: `npm run build` в папке client
2. Перетащите папку `build` на https://app.netlify.com/drop
3. Готово! Получите URL типа: `https://random-name-123.netlify.app`

Откройте http://localhost:3000 на своем ноутбуке и показывайте со своего экрана (подключив к проектору/демонстрации экрана).
