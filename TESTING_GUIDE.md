# Краткая инструкция по тестированию системы рекомендаций

## Что реализовано

✅ **Два блока рекомендаций в калькуляции (CalculationResults):**
1. **Рекомендации для сотрудника** - с тремя полями и кнопкой отправки
2. **Управленческие рекомендации** - для руководителя с кнопкой отправки
3. **Общие заметки** - для внутреннего использования HR (БЕЗ кнопки ИИ)

✅ **Интеграция с AI микросервисом:**
- Кнопка "🤖 Помощь ИИ" для автоматической генерации рекомендаций
- Отправка данных на `http://localhost:8000/api/results-and-plan` (для сотрудника)
- Отправка данных на `http://localhost:8000/api/steps-of-manager` (для руководителя)
- Автоматическое заполнение полей из ответа AI

✅ **Отображение рекомендаций:**
- В дашборде сотрудника появляется красивый блок с рекомендациями
- Рекомендации разделены на три секции с иконками
- Цветовое кодирование (достижения - зеленый, улучшения - синий, план - оранжевый)

✅ **База данных:**
- Созданы таблицы `employee_recommendations` и `manager_recommendations`
- Добавлены индексы для быстрого поиска

## Как протестировать

### 1. Запустите проект

```bash
cd "c:\Users\Елена\Documents\Хакатоны\Расти в IT"
.\START_FULL.ps1
```

### 2. Войдите как HR

- Email: `hr@wink.com` (или другой HR пользователь)
- Перейдите в HR Dashboard → Калькуляция результатов
- Выберите любого сотрудника

### 3. Протестируйте ручной ввод рекомендаций

**Рекомендации для сотрудника:**
- Заполните поля вручную
- Нажмите "📧 Отправить сотруднику"
- Проверьте, что появилось уведомление об успехе

**Управленческие рекомендации:**
- Заполните поле вручную
- Нажмите "📧 Отправить руководителю"
- Проверьте уведомление

### 4. Протестируйте AI генерацию (если AI микросервис запущен)

**Если AI микросервис НЕ запущен:**
- Нажмите "🤖 Помощь ИИ"
- Должна появиться ошибка: "Проверьте, что AI микросервис запущен на http://localhost:8000"
- Это нормальное поведение

**Если AI микросервис запущен:**
- Нажмите "🤖 Помощь ИИ"
- Кнопка должна измениться на "⏳ Генерация..."
- После генерации поля должны автоматически заполниться
- Появится уведомление "✨ Рекомендации успешно сгенерированы с помощью AI!"

### 5. Проверьте отображение в дашборде сотрудника

- Выйдите из аккаунта HR
- Войдите как сотрудник, которому отправили рекомендации
- На главной странице должен появиться блок "📋 Рекомендации от HR"
- Проверьте, что все три секции отображаются правильно

## Важные моменты

1. **Кнопка "🤖 Помощь ИИ" есть ТОЛЬКО в двух блоках:**
   - Рекомендации для сотрудника
   - Управленческие рекомендации
   
2. **Блок "Общие заметки" НЕ имеет кнопки ИИ** - это для внутренних заметок HR

3. **AI микросервис опционален** - можно работать без него, заполняя вручную

4. **Все данные сохраняются в БД** и доступны через API endpoints

## Endpoints

- `POST /api/hr/send-employee-recommendations/:id` - Отправить рекомендации сотруднику
- `POST /api/hr/send-manager-recommendations/:id` - Отправить рекомендации руководителю
- `GET /api/employee/my-recommendations` - Получить свои рекомендации
- `GET /api/manager/recommendations` - Получить рекомендации по команде
- `POST /api/recommendations/mark-read/:id` - Отметить как прочитанное

## Если что-то не работает

1. Проверьте консоль браузера (F12) - там логи AI запросов
2. Проверьте консоль сервера - там логи отправки рекомендаций
3. Проверьте, что таблицы созданы: `node server/create-recommendations-tables.js`
4. Проверьте подключение к базе данных
