## ЛУЧШЕЕ РЕШЕНИЕ: Ngrok (без паролей!)

### 1. Скачайте Ngrok:
https://ngrok.com/download

### 2. Распакуйте в папку (например, C:\ngrok)

### 3. Зарегистрируйтесь на ngrok.com и получите токен

### 4. Запустите:
```powershell
cd C:\ngrok
.\ngrok config add-authtoken ВАШ_ТОКЕН
.\ngrok http 3000
```

Получите красивый URL без паролей типа: `https://abc123.ngrok-free.app`

## Альтернатива: Deploy на бесплатный хостинг

### Vercel (РЕКОМЕНДУЮ для хакатона):

1. Создайте аккаунт на vercel.com
2. Установите Vercel CLI:
```powershell
npm install -g vercel
```

3. Deploy фронтенда:
```powershell
cd client
vercel --prod
```

Получите постоянный URL типа: `https://wink-performance-review.vercel.app`

### Netlify:
```powershell
npm install -g netlify-cli
cd client
npm run build
netlify deploy --prod
```
